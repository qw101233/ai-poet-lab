📖 关于 AI Poet Lab

什么是 AI Poet Lab？

AI Poet Lab 是一个基于浏览器的智能诗歌创作实验室。它内置了基于意象组合与韵律约束的诗歌生成引擎，能够根据用户输入的主题和情感，实时生成唐诗、宋词和现代诗三种风格的诗歌作品。

核心特性

  • 🎭 三种诗歌风格：唐诗绝句、宋词长短句、现代自由诗
  • 🌈 八种情感基调：思乡、离别、壮志、爱情、田园、咏物、感怀、豪放
  • 🔊 Web Speech API 诗歌朗读
  • 🖼️ Canvas 意境配图生成
  • ⭐ 本地收藏管理
  • 🎨 水墨中国风界面设计

技术实现

纯前端实现（HTML + CSS + JavaScript），零外部依赖，开箱即用。诗歌生成引擎基于意象库、韵律库和句式模板的组合算法，每首诗都是独一无二的。
